┌────────────────────────────────────────────────────────────────┐
│  USEFUL COMMANDS                                               │
└────────────────────────────────────────────────────────────────┘

  View logs:
  docker-compose logs -f
  
  View AI logs only:
  docker-compose logs -f remediation_engine
  
  Stop application:
  docker-compose down
  
  Restart a service:
  docker-compose restart api_service
  
  Check status:
  docker-compose ps


┌────────────────────────────────────────────────────────────────┐
│  TROUBLESHOOTING                                               │
└────────────────────────────────────────────────────────────────┘

  Problem: Services won't start
  Solution: Check if ports are in use
  
  netstat -ano | findstr "8000 9090"
  
  
  Problem: Metrics show 0.0
  Solution: Rebuild containers
  
  docker-compose down
  docker-compose up --build -d
  
  
  Problem: Dashboard not loading
  Solution: Check API logs
  
  docker-compose logs api_service
